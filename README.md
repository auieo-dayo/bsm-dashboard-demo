## [BSW](https://github.com/auieo-dayo/bsw)のwww/に配置で動くダッシュボードのデモ達

### 同封されているダッシュボード
- `/Controler/` - PC用に最適化したダッシュボード
- `/phone/` - スマホ用に最適化したダッシュボード
- `/tui/` - PC用に最適化した、TUI風のダッシュボード
- `/simple/` - PC、スマホ用に最適化した、標準搭載ダッシュボード
